# Tunisia Accessibility

Community-driven accessibility platform for Tunisia. Mobility-first.
From the people, to the people. No ads, no sponsors, no paid placements.

## Structure

- `backend/` — ASP.NET Core 10 API (.NET 10)
- `mobile/` — Flutter app (Android-first)
- `web/` — Next.js companion (public pages + NGO admin)
- `infra/` — Docker, deployment scripts
- `docs/` — design decisions, architecture notes
